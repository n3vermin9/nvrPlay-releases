# NvrPllst for Windows

This public repository contains Windows installers and automatic-update metadata for NvrPllst. The application source, backend, account data, and credentials are kept in a separate private repository.

Download the latest `NvrPllst-Windows-*.exe` installer from [Releases](https://github.com/n3vermin9/nvrPlay-releases/releases/latest). After this updater-enabled version is installed once, future NvrPllst releases can be downloaded and installed from inside the app.
